# ⏱️ Chronos Pomodoro

Um aplicativo de timer Pomodoro moderno e elegante, construído com React e
TypeScript, para ajudar você a maximizar sua produtividade e gerenciar melhor o
seu tempo.

## 🚀 Começando

Essas instruções permitirão que você obtenha uma cópia do projeto em operação na
sua máquina local para fins de desenvolvimento e teste.

### 📋 Pré-requisitos

De que coisas você precisa para instalar o software e como instalá-lo?

```bash
# Node.js (versão 18 ou superior)
node --version

# npm (normalmente instalado junto com Node.js)
npm --version
```

### 🔧 Instalação

Uma série de exemplos passo-a-passo que informam o que você deve executar para
ter um ambiente de desenvolvimento em execução.

Clone o repositório:

```bash
git clone https://github.com/seu-usuario/chronos-pomodoro.git
```

Entre no diretório do projeto:

```bash
cd chronos-pomodoro
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

O aplicativo estará disponível em `http://localhost:5173`

## ⚙️ Executando os testes

Explicar como executar os testes automatizados para este sistema.

### 🔩 Linting

Para verificar erros de código e estilo:

```bash
npm run lint
```

### ⌨️ Build de produção

Para gerar a versão de produção:

```bash
npm run build
```

Para visualizar a versão de produção localmente:

```bash
npm run preview
```

## 📦 Implantação

Para implantar em produção, execute o comando de build e sirva os arquivos da
pasta `dist`:

```bash
npm run build
```

Os arquivos otimizados estarão na pasta `dist/`, prontos para serem hospedados
em qualquer servidor estático ou plataforma como Vercel, Netlify, GitHub Pages,
etc.
